# Cash Ready Homes Hudson Valley: static site

React + Vite + Tailwind site, **prerendered to static HTML** at build time and hosted on
Cloudflare Pages. Moved off Manus in Oct 2026 (no server, no database).

## Commands
| | |
|---|---|
| `pnpm install` | install deps (Node 20+; Node 22+ for `wrangler`) |
| `pnpm dev` | local dev server (no /api/lead) |
| `pnpm build` | generate `_redirects`, build client + SSR bundle, prerender every route to `dist/public/*.html`, write `sitemap.xml` + `robots.txt` |
| `pnpm preview` | `wrangler pages dev dist/public`: serves the build **with** `_redirects`, `_headers` and `functions/` locally |
| `node scripts/test-lead.mjs` | offline tests for the lead function (mocked fetch) |
| `python3 scripts/compare_live.py` | compare built title/description/canonical/H1 against a saved crawl |

Cloudflare Pages settings: **Build command** `pnpm build`, **Output dir** `dist/public`, Node `NODE_VERSION=22`.

## Layout
- `client/src/pages/*`: pages. Routes are in `client/src/App.tsx`. The route list for prerender and sitemap is in `scripts/prerender.mjs`.
- `content/blog/*.md`: **blog posts** (frontmatter + Markdown), bundled at build time by `client/src/lib/blog.ts`.
- `client/public/manus-storage/*`: images (self-hosted copies of the old Manus storage; paths kept identical).
- `functions/api/lead.js`: Cloudflare Pages Function behind the lead form (validation, honeypot, REsimpli, email copy).
- `client/public/_redirects`: generated by `scripts/gen-redirects.mjs` (legacy URL 301s). `_headers` has cache headers.
- `scripts/data/manus-posts-export.json`: raw export of the 22 posts from the Manus site (Oct 26 2026).

## Publishing the Monday blog post
1. `pnpm new-post "How to Sell a House With Code Violations in Yonkers"` (options: `--category "Selling Tips"`, `--image /manus-storage/blog/yonkers.jpg`).
   Or just drop a file `content/blog/<slug>.md` with this frontmatter:
   ```
   ---
   title: "Post title (H1)"
   slug: "url-slug"
   date: "2026-11-02T13:00:00.000Z"
   updated: "2026-11-02T13:00:00.000Z"
   category: "Selling Tips"
   excerpt: "Shown on /blog."
   metaTitle: "≤60 char <title>"
   metaDescription: "~155 char meta description"
   featuredImage: "/manus-storage/blog/image.jpg"
   published: true
   ---
   ## First heading
   Markdown body…
   ```
   Values are JSON strings (keep the quotes). Body supports `##`/`###`/`####`, `-`/`*` lists, `1.` lists, `**bold**`.
2. Put the image (≤300 KB JPG/WebP, ~1600px wide) in `client/public/manus-storage/blog/`.
3. `pnpm build` (the post is prerendered, added to `/blog`, and added to `sitemap.xml` with its `updated` date), then commit + push.
   Cloudflare Pages rebuilds on push. `published: false` hides a draft.

## Lead form env vars (Pages → Settings → Variables and Secrets)
- `RESIMPLI_API_TOKEN` (secret, **required**). `RESIMPLI_WEBFORM_LINK` is optional (defaults to `6977ca6a5c1fcabc2e8dcb3e`).
- Email copy: `EMAIL_PROVIDER` = `resend` | `mailchannels` | `webhook` (unset = no email), `EMAIL_API_KEY`, `EMAIL_WEBHOOK_URL`, `LEAD_EMAIL_TO` (default jack@cashreadyhomeshudsonvalley.com), `LEAD_EMAIL_FROM`.
- Analytics: set `CF_BEACON_TOKEN` (build env) to inject Cloudflare Web Analytics, or enable Web Analytics on the Pages project, which injects it automatically.

Leads are no longer stored in a database; REsimpli plus the email copy are the record.
